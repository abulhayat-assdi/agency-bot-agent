# Dashboard Analytics

Milestone 6 replaces placeholder overview/client/account pages with real dashboard surfaces powered by the deterministic mock Meta adapter and analytics engine.

## Implemented pages

- `/dashboard`: agency overview with date/client/account filters, KPI cards, performance trend chart, currency-safe financial summaries, top campaign ranking, deterministic alerts, data freshness, and caveats.
- `/clients`: client portfolio list with delivery metrics.
- `/clients/[clientId]`: client overview with connected accounts and consolidated metrics.
- `/ad-accounts`: connected account registry with timezone, currency, access status, and reporting metrics.
- `/ad-accounts/[accountId]`: account overview with account metadata, report tabs, KPI grid, and campaign reporting table.

## Data source

Dashboard data is generated by `src/server/dashboard/mock-dashboard-data.ts` using the read-only `MockMetaAdsProvider`. No live Meta data is displayed yet.

## Accuracy rules

- Financial metrics are grouped by account currency.
- Multi-currency selections do not silently aggregate spend/value/CPA/ROAS into one fake currency.
- Delivery metrics such as impressions, reach, clicks, CTR, and conversions may be aggregated across selected accounts.
- Metrics preserve availability states from the analytics engine.
- Unavailable/null/unsupported values render as `Unavailable`, not zero.
- Alerts are deterministic anomaly-engine output, not AI-generated claims.

## Filters

The dashboard supports link-driven filters for:

- date preset
- client
- ad account

Implemented date presets:

- Today
- Yesterday
- Last 3 Days
- Last 7 Days
- Last 14 Days
- Last 28 Days
- Last 30 Days
- This Month
- Last Month

Custom date ranges are planned for the trends/comparison milestone.

## UX components

- `KpiCard`: state-aware metric card.
- `FilterBar`: date/client/account filter navigation.
- `PerformanceTrendChart`: Recharts-based delivery/click/conversion trend chart.
- `MetricsTable`: responsive table with sticky first column.

## Known limitations

- Search, sort controls, pagination controls, column visibility, and CSV export are planned for later table/report milestones.
- Campaign/ad-set/ad deep reporting pages are planned for the next milestone.
- Data is mock-backed until live read-only Meta integration is implemented.
